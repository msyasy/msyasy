## About

I am a **Full-Stack Developer** and Informatics graduate from Universitas Indraprasta PGRI (2025). I build web applications end to end: REST APIs in Go, React frontends, and relational databases in PostgreSQL and MySQL.

My current projects are **LowonganKita**, a directory of career pages from Indonesian companies, and **LapKeu**, a personal finance manager that grew out of a daily spreadsheet. Both include authentication (JWT, OAuth, passkeys), rate limiting, and database-level access control.

Before that, I worked as a software developer intern and as a state asset (BMN) management intern, which gave me hands-on experience with administration, inventory, and reporting.

**Open to:** Full Stack Developer · Backend Developer · Software Engineer (entry-level)
